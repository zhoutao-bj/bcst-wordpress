# BCST 工业品展示及询价网站

基于 WordPress 7.1.2，开发兼容目标 PHP 7.4 / MySQL 5.7。主题独立运行，无付费父主题依赖。核心文件未修改。

- `wp-content/themes/bcst-industrial`：响应式首页、产品列表/分类/详情、文章、普通页面、搜索、404、语言入口。
- `wp-content/plugins/bcst-core`：产品与三级分类、字段、询盘入库及邮件、状态与备注、CSV 导出、基础页面初始化、联系人设置。
- 多语言采用另行安装的 Polylang：产品、分类、页面、文章可翻译；主题文案通过“语言 → 字符串翻译”翻译。未翻译页面不展示对应切换入口。支持 RTL 排版。
- SEO 基础：语义化标题、WordPress 原生 sitemap/canonical、摘要描述。完整 SEO 字段和社交分享元数据交给另行安装的 SEO 插件。
- 图文、视频、目录、证书、产品参数均由后台编辑；未复制 BCST 品牌、照片和商业资料。

## 当前交付边界

这是待部署验收的首版代码，非已在生产实测的网站。基础公司/行业/资源页面含明确占位提示，上线前必须替换。演示产品为草稿。后台初始化后可开始录入内容。

不含在线交易。未实现自动翻译、附件询盘上传、CRM 分配、询盘自动重发、产品对比、专用行业数据模型、自动生成技术文章。行业方案和资源通过普通页面及区块编辑；案例和技术培训通过文章分类维护。产品型号建议写进产品标题或正文，默认搜索不检索自定义参数字段。

邮件依赖实际 SMTP；后台“邮件已接受”不代表客户邮箱收到。GA4、Meta Pixel、TikTok Pixel 尚未接入，需客户账号、ID 和隐私/同意方案。已提供 UTM 标签记录和联系点击事件供后续接入，不自动加载第三方跟踪代码。
